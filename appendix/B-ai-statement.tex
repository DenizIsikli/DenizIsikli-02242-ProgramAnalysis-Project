\section{AI-Use Statement}
\label{app:ai}

The course allows AI tools if their use is stated. We used the following.

\paragraph{Deniz Isikli}
Deniz used Claude Code (Anthropic, model Claude Opus 5.5) as an assistant. It drafted
the design documents in \code{docs/refactoring/}: the observation contract, the verdict
rules with their correctness arguments, the review of the interval primitives and the
corpus, and the soundness notes for the interval operations. It reviewed the second pull
request against those documents. In that review it found the exception-handler soundness
gap described in \cref{sec:threats}, and it wrote the fix and the regression test. It
also built the decompiled corpus with the course's \code{jvm2json} image and added a test
that checks every regional verdict against the real-JVM observations. For this paper it
completed the draft. It added the bibliography, checking every entry against its DOI,
turned the guarantees into theorems with proofs, added the evaluation sub-questions and
corrected the description of the \code{sign} pair.

Deniz checked the output in three ways:
\begin{itemize}
  \item by reading and discussing every argument before accepting it;
  \item by re-running the test suite (184 tests) and the ablation script, and comparing
        every number in \cref{tab:results,tab:perpair} with the regenerated output;
  \item by checking the claims about Z3 and interval semantics directly with the solver
        and with a brute-force test.
\end{itemize}
